# Skills Curadas

Este directorio quedó reducido a skills que sí aportan al bot en estas áreas:

- estructura y diseño de módulos
- seguridad y hardening
- calidad, testing y CI
- mantenibilidad y simplificación
- operación segura del runtime de trading

## Skills clave para este proyecto

- `runtime-ops-and-trading-safety`: reglas específicas del bot para conectividad, ejecución, reconciliación y recovery
- `security-and-hardening`: seguridad general y tratamiento de datos externos/no confiables
- `code-review-and-quality`: revisión por correctness, arquitectura, seguridad y performance
- `test-driven-development`: pruebas de regresión y cambios guiados por tests
- `debugging-and-error-recovery`: diagnóstico disciplinado de fallos y arranque
- `ci-cd-and-automation`: refuerzo de quality gates
- `documentation-and-adrs`: decisiones técnicas y contexto durable
- `code-simplification`: mantener bajo control la complejidad

## Skills conservadas por utilidad transversal

- `api-and-interface-design`
- `context-engineering`
- `deprecation-and-migration`
- `git-workflow-and-versioning`
- `incremental-implementation`
- `performance-optimization`
- `planning-and-task-breakdown`
- `source-driven-development`
- `spec-driven-development`
- `shipping-and-launch`

## Skills eliminadas

- `browser-testing-with-devtools`: fuera de foco para el backend/runtime del bot
- `frontend-ui-engineering`: no es una necesidad principal de este proyecto
- `idea-refine`: útil para ideación general, no para operación/mantenimiento del bot
- `using-agent-skills`: meta-skill redundante dentro del repositorio
